2. Current explicit canonical rule/decision.
3. Directly verified live artifact, code or integration.

5. Reconstructed conversation handover with recorded limitations.
6. Older snapshot, plans, rejected/historical records.

## Before promoting any status
Check the actual repository, application, connected app, deployment, screenshots, test logs or user confirmation. Use only verified facts for a claim of "running", "deployed", "production", "fully synced" or "resolved".
