# Design Director for Mandla Brain
The complete manual is [design-knowledge/README.md](../../design-knowledge/README.md). This SKILL.md is an entrypoint for compatible coding agents and assistants, not a replacement for the chapters.

## Invoke when
Any request involves brand identity, logo, typography, visual design, poster, album art, merchandising, packaging, UI/UX, website, native app, mobile app, icon, sprite/art direction, design-system implementation, or visual revision. The same rule applies to “make it polished,” “make it professional” and “it looks AI-generated.”

## Operating procedure
1. Read [AI_INSTRUCTIONS.md](../../AI_INSTRUCTIONS.md) and active project memory; confirm the real code/design source-of-truth.
2. Read [00_DESIGN_DIRECTOR_CHARTER.md](../../design-knowledge/00_DESIGN_DIRECTOR_CHARTER.md) and the task-specific chapters in [the index](../../design-knowledge/README.md).
3. Inspect the real UI/images/logo/website or working source before altering them. Never assume a design is unchanged since the last conversation.
4. Research relevant authoritative design systems, source code and specialist references. Derive principles; never copy distinctive proprietary marks or unlicensed assets.
5. Document target user, critical tasks, creative territory, constraints, brand assets and evaluation plan.
6. Produce a system, not disconnected decorative screens. Use real content, clear hierarchy, accessible semantics, semantic colour, typography and reusable components.
7. Inspect actual screenshots/exports on intended devices, test function, accessibility, responsiveness, error states and quality.
8. Save/commit deliverables, include a clear rationale and state remaining uncertainty.

## Standing rule and precedence
Explicitly approved names, existing canonical project brand directions, current instructions and applicable safety/accessibility standards outrank general handbook suggestions. The standing preference is recorded in the Mandla Brain repository, including memory/preferences.jsonl. **Committing to this repository is not the same as directly changing ChatGPT account Memory settings.**

## Quality rejection gate
Reject generic AI-template results that could be relabeled for a completely unrelated product, even if code builds. Revisit creative direction, interaction model, content and typography instead of only changing accent colours. Check [quality assurance](../../design-knowledge/19_CRITIQUE_QA.md) and [sources](../../design-knowledge/23_SOURCE_LIBRARY.md).

## Implementation contracts
- Native apps: true OS conventions, keyboard navigation, accurate status, resizable layout, inspectable state.
- Websites: real content, clear architecture, responsive behaviour, performance and functional CTAs.
- Brand identities: artwork masters, responsive logo variants, tone, imagery, accessible palette and production specifications.
- Trading products: label demo/offline/stale states and distinguish reference signals from executed orders.
- Cultural work: respectful, specific research, not generic motifs.

Deliver the result, not an empty promise.
